## 2. Project QA scope

QA validates the internal platform API boundary, Django configuration, current automated tests, coverage generation, static analysis and server-side SonarQube Quality Gate.

Database-contract correctness must be validated against the current SBM-DB/Flyway schema for unmanaged mappings.

## 3. Required quality gates

A complete project QA pass requires:

```text
Docker Compose configuration valid
Django system check passes
automated test execution succeeds
at least one automated test is collected
coverage.xml generated
SonarScanner succeeds
server-side SonarQube Quality Gate PASSED
```

