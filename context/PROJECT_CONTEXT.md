## 1. Executive summary

SBM-API is the internal platform API of SBM Suite. It is a Django REST Framework service for platform administration and internal operational domains, exposed locally on host port `8082` through the `sbm-core` container.

## 2. Project purpose

Provide internal/platform REST operations for franchises, configuration, fiscal behavior, inventory, calculation, modules, users and related platform domains while keeping the client-facing DP-API boundary separate.

## 10. Data model ownership

SBM-API maps PostgreSQL data through Django models. The supplied repository contains both managed models and explicit `managed = False` mappings across multiple schemas.

Physical schema authority belongs to SBM-DB/Flyway where the Suite contract defines database ownership. Unmanaged models must match the physical schema and must not generate independent schema evolution.

## 16. Database and migration impact

This Suite integration adds project context and QA tooling only. It does not add, remove or modify Django migrations, Flyway migrations, DBML, PostgreSQL structures or domain models.

The supplied Docker entrypoint currently executes Django `migrate`; this existing behavior is documented but not changed by this integration.

## 17. Security considerations

- `.env.dev` contains environment-managed secrets and must remain untracked.
- `SECRET_KEY`, database credentials and `SONAR_TOKEN` must never enter Context or QA artifacts.
- `CORS_ALLOW_ALL_ORIGINS = True` is present in the supplied development settings and requires production hardening.
- Authorization and tenant/franchise isolation require dedicated validation.
- Docker entrypoint defaults and administrative bootstrap behavior require separate production review.

## 18. Accepted risks and constraints

- Current app-level `tests.py` files do not provide an evidenced complete automated-test baseline.

- Existing repository changes to `.gitignore`, `docker-compose.yml` and deletion of `TECHNICAL_DOCUMENTATION.md` predate this integration and are preserved as user-owned state.
